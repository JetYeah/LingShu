# 灵枢 LíngShū

> 身有灵枢 · 健康有度 —— 阴阳五行 × 中医风格的个人/家庭健康管理 App

「灵枢」取自《黄帝内经·灵枢》（专论经络穴位之篇），"枢"亦喻健康数据之枢纽。

## 功能总览

| 模块 | 说明 |
|------|------|
| 3D 经穴铜人（首页） | 男女两版青铜人体模型，单指旋转/双指缩放/点击穴位查看拼音、定位、功效、主治、按摩方法；按经络筛选高亮、搜索定位 |
| 健康档案库 | 拍照/相册/任意文件上传，AI 自动识别日期、医院、科室、报告类型与指标，按「人→年→月」归档，记录提交时 GPS 地址（可手动改为医院名） |
| 家庭成员档案 | 姓名/性别/生日/身份证(加密)/血型/Rh/过敏源/慢病史/家族史/紧急联系人，多成员一键切换 |
| 健康指标追踪 | 血压/血糖/心率/体重/体温/血氧等预设 + 自定义任意指标，趋势图 + 参考区间带 + 异常标记 |
| 用药提醒 | 每日多时间点本地通知提醒，服药打卡/漏服标记，库存记录 |
| 急救指南 | 26 个急救场景（CPR、海姆立克、中风 FAST、烫伤、蛇咬伤…）整理自 IFRC《国际急救、复苏和教育指南》，离线可用，SOS 一键拨打 120 |
| 中医养生 | 九种体质辨识问卷与养生建议、节气/子午流注养生卡片、五行配色体系 |

## 技术栈

- Flutter 3.x + Riverpod + go_router
- Drift (SQLite) + SQLCipher：数据库整体加密，密钥存于应用私有目录；健康数据不出本机
- 视觉大模型 OCR（OpenAI 兼容协议，默认 glm-4v-flash），在「我的→设置」配置 API Key
- fl_chart 指标图表；flutter_local_notifications + timezone 用药提醒；geolocator/geocoding 定位；local_auth 生物识别
- 3D 铜人为纯 Flutter 自研软件渲染（球体+胶囊体建模 + 自定义光照投影），无外部模型依赖

## 数据说明

- 穴位数据：141 穴（十四经 + 常用奇穴），内容整理自公开中医资料；3D 坐标为解剖学估算，可在
  assets/data/acupoints/*.json 的 pos 字段调整（坐标系：身高 1.72m，脚底 y=0，面向 +Z，x 左右对称）
- 急救内容：参考 IFRC《国际急救、复苏和教育指南》(2020) 与中国红十字会公开资料整理，仅供学习参考
- 免责声明：本应用不能替代专业医疗建议与急救培训

## 运行

    flutter pub get
    flutter run

Android 权限：定位、相机、通知（含精确闹钟）、生物识别。首次启动需创建主人档案并设置 PIN。
